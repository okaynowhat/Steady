# Decisions

Every choice made while building from `SPEC.md` (the brief of 14 Oct 2026) that the spec left open, plus the maintainer's answers. Newest at the bottom. Change a decision by adding a new line that supersedes it, not by editing the old one.

| # | Date | Decision | Why |
|---|---|---|---|
| D1 | 2026-10-14 | Licence GPL-3.0. Code lives in `okaynowhat/steady`, created empty and private by the maintainer; making it public is the maintainer's call once the translations are reviewed. | The maintainer's answer. Same licence as Clear Seeing and Floating Notes. |
| D2 | 2026-10-14 | Help numbers as in `HELP-NUMBERS.md`, checked 2026-10-14. Brazil 190 and Portugal SOS Voz Amiga left out because no current source confirmed them. Estonia 116 123 shipped without hours. | Spec section 11: never ship an unverified number as fact. |
| D3 | 2026-10-14 | One `index.html` holds all HTML, CSS and JS. `manifest.webmanifest`, `sw.js` and two PNG icons sit next to it for the PWA. The APK ships the same `index.html`. | Spec section 14. |
| D4 | 2026-10-14 | Starter packs are a shared base (moves, habits, review prompts, one-time setup, help texts) plus per-pack overrides (quotes, rules, daily checklist, checkpoint questions), per language. | Spec 6.17 says structure is identical and packs differ mainly in those four lists. Keeps the file small. |
| D5 | 2026-10-14 | English is the source. Estonian and Brazilian Portuguese are drafted by Claude, every block marked `// review`, and Settings shows "Translation not yet reviewed" for those two languages until a native speaker signs off. | Spec section 10 requires native review before release. |
| D6 | 2026-10-14 | Time is read through one `now()` function; tests use Playwright's clock API rather than test hooks in the app. | Spec section 15 asks for mocked clocks; no test-only code ships. |
| D7 | 2026-10-14 | The daily key is the local date of (now minus the reset time). The week key is the ISO week of the local date; with a Sunday start, Sunday counts toward the following ISO week. | Spec 8 and 6.12. |
| D8 | 2026-10-14 | Changing the starter pack replaces only the lists that are still unedited. Lists the user has changed are kept; "Reset to starter content" is per list. | Protects the user's own words, spec principle "everything is editable". |
| D9 | 2026-10-14 | Import offers Replace or Merge. Merge adds records and list items whose ids are not present and keeps current settings. | Spec 12 names both without detail. |
| D10 | 2026-10-14 | Android build: export copies the JSON to the clipboard and shows it in a text box; the PWA downloads a file. The app detects Android by the `file:` protocol. | Spec 12 for v1. |
| D11 | 2026-10-14 | The APK requests VIBRATE (for the optional breath vibration) and nothing else. No INTERNET permission. | Spec 6.4 allows optional vibration; VIBRATE grants no network access. |
| D12 | 2026-10-14 | Section labels stay uppercase with letter spacing, as the spec's design system says, despite general advice against it. | The spec is the brief; it wins over defaults. |
| D13 | 2026-10-14 | The signing keystore is new, generated in this session, delivered to the maintainer as a file with its passwords, and never committed. `.gitignore` excludes `*.jks` and `keystore*`. | Spec 14: keep the same key for all future updates. |
| D14 | 2026-10-14 | Package `ee.steady.calm`, minSdk 26, targetSdk 34, versionName 1.0.0, versionCode 1. | Spec 14. |
| D15 | 2026-10-14 | A 1-minute worry duration exists only when the URL has `?test=1`, so the automated test can check the due state. It is not offered to users. | Spec 15 asks for a 1-minute test duration. |
| D16 | 2026-10-14 | Four light-theme colours darkened to meet the spec's own WCAG AA rule: muted text #7d8a85 to #5f6c67 (3.3 to 5.0 on bg), warm text #b07a5a to #8a5a3c (3.1 to 5.0 on warm-soft), primary buttons use accent-deep #4f7d70 behind white text (4.7), and the SOS gradient runs #6a978a to #4a786b with large bold text (3.3 to 5.0). Accent and warm stay as the spec says for borders, fills and the orb. Dark theme passes as specified. | Spec 7 and 13 conflict; accessibility is a hard requirement, the exact hex values are not. |
| D17 | 2026-10-14 | Additions to the data model: `settings.sos.nightLine`, `settings.statNoChecking`, `settings.worryDur`, `content.texts` (SOS label, Name it lines, night banner), `content.meta.edited`, `state.journalDraft`, `state.reviewDraft`, `state.checkpointNotes`, and `cleared` and `reviewedAt` on worries. | The spec makes these texts editable and these settings optional without naming fields for them. |
| D18 | 2026-10-14 | The Name it, wave and summary copy for the separation and general stress packs was written in this session, following the spec's content principles, since the spec gives full text only for the relationship pack. | Spec 6.17 asks for three packs. |
| D19 | 2026-10-14 | The APK sets `allowBackup="false"` so Android's cloud backup cannot copy entries to a Google account. Exports remain the only way data leaves the phone. | Spec 12: nothing leaves the phone. |
| D20 | 2026-10-14 | The launcher activity uses `launchMode="singleTask"`, so tapping the icon while Steady is open returns to the running flow instead of starting a second copy. | Keeps an SOS flow in progress intact. |
| D21 | 2026-10-14 | Fixed during testing: the page could leave its last control under the floating tab bar (a CSS specificity slip removed the bottom padding), and checkbox focus blocked the minute refresh. Both have tests now. | Found by the browser tests. |
